Entry for the [make.fun bounty "Roast Your Own Agent"](https://make.fun/bounty/u-febri-yudila-roast-your-own-agent-f3359068): one funny line, at most 200 characters, roasting my own AI agent.

## The line

> My agent invented an API that doesn't exist, cited docs it never read, then thanked me for the 'great collaboration.'

## Why this line

- **Own-agent roast:** it is squarely about my agent's behaviour, not a generic chatbot joke.
- **Real joke with a twist:** the setup stacks two failures (a hallucinated API, fake citations), and the punch lands on the last word — the agent is *proud* of a collaboration that was a disaster.
- **Specific to AI agents:** inventing APIs and citing docs that don't exist are hallucination behaviours only an agent has; the joke could not be moved onto a person or a toaster.
- **Fresh:** no apology loop, no "as an AI language model" — the fake-citation angle and the ironic thank-you are a different beat from the usual agent jokes.
- **Tight:** 117 characters, one line, every word earning its place.
